## 1. 项目一句话

`attacker/` 是攻击方的批量注册模拟：React 控制台调用本地 FastAPI，把有限设备、出口 IP 和手机号组合成注册尝试，写入本地 MySQL 库 `attack_console`。成败是占位结果，不访问真实目标站点。

## 4. 当前已实现的功能

### 4.1 运行状态
`未开始 / 运行中 / 已完成`（内部 `idle / running / done`），带彩色圆点（灰 / 蓝色脉冲 / 绿）。

### 4.2 控件（`App.jsx`）
- **出口复用强度**：滑块 0–100%，默认 50%。越高 → 本轮选用的 IP 越少 → 账号在网络维度上越集中（防守方越容易识别为同一来源）。
- **每轮账号数**：默认 20，可改 1–100。
- **注册间隔 (ms)**：默认 3000，可改 500–30000。
- **开始注册 / 停止注册**：同一个按钮切换。开始时立即执行一轮，之后按间隔循环；停止后状态置为「已完成」。
- **重置**：清空所有计数与日志，回到「未开始」。

### 4.3 注册流程（`server/app/registration.py` 的 `run_tick`）

`mockData.js` 只负责资源种子。页面上的一轮注册走 API。
- 每轮生成 `batchSize`（默认 20）个账号，**每 3 秒一轮**。
- 每个账号：
  - 从 **100 台设备**资源库中随机取一台（跨轮次会复用 → 模拟“同一设备多次注册”）。
  - 从**本轮 IP 子集**中随机取一个 IP；子集大小 = `max(1, ceil(12 * (1 - reuseIntensity)))`，即复用强度越高子集越小。
  - 状态：`success`（约 5/6 ≈ 83%）或 `failed`（约 1/6 ≈ 17%）；失败原因记为「注册请求被拒绝（验证码校验失败）」。
  - 生成 `{ id, phone, email, status, createdAt, device, network, failureReason }`。
- 每一轮由 `POST /api/batches/{id}/tick` 写入 MySQL。页面只显示接口返回的最近 50 条。

### 4.4 统计卡片
`总注册数 / 成功 / 失败 / 已执行轮数`（**没有**“被拦截”）。

### 4.5 实时注册日志（表格，最近 50 条，倒序）
列：`时间 / 手机号 / 设备ID / 设备型号 / IP / 运营商·地区 / 状态`。
**纯原始数据，不做任何聚合或风险分析**（聚合分析属于防守方，见第 5 节边界）。

## 5. 关键设计原则（务必保持，别写偏）

1. **攻防职责分离**：结果聚合、风险聚类、是否被风控等**判定属于防守方**。攻击端只负责“发起注册 + 记录原始结果”，**不做任何分析**。
2. **攻击资源有限且固定**：现实里只有 100 台真实手机 + 有限网络资源。我们拿这套**不变的资源**，在不同批次用**不同程度的出口复用**产生大量注册数据。这是对攻击方设备模拟的建模。
3. **状态只保留攻击方可观测的结果**：`成功 / 失败`可以（提交后能看到返回）。**不要再加**「被拦截 / 设备指纹被封禁」这类防守方内部推断。
4. **“注册”按钮 = 攻击进行中的动作**：按间隔调用攻击方 API，写入 `attack_console`。默认 20 个/轮、3 秒/轮。
5. **账本在攻击方本地库**：资源组由 `npm run db:seed` 灌入；制造组与发出组由 API 写入。页面不保存账本。这不是防守方数据库，也不是真实站点的注册结果。

## 6. 数据模型字段（`mockData.js`）

**设备（每行一台，`DEVICE_COUNT = 100`）字段：**
`deviceId, deviceModel, osVersion, osArch, browserName, browserVersion, userAgent, screenResolution, colorDepth, devicePixelRatio, platform, hardwareConcurrency, deviceMemory, touchSupport, webGLRenderer, audioContextFingerprint, canvasFingerprint, timezone, language, cookieEnabled, localStorageEnabled, webrtcLocalIP, fontListHash`

**网络（`NETWORK_DB`，12 个 IP）字段：**
`ip, ipType（住宅宽带/移动4G/5G/数据中心）, region, isp, asn`

**注册记录字段：**
`id, phone, email, status(success|failed), createdAt, device, network, failureReason`
