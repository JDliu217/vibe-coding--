# check_quest · 提问记录

这个文件夹用于记录**每个 commit 区间内，我向 AI 提出的问题**，方便之后让另一个 AI 做 review / check 时快速了解：

- 每个区间我关注了什么
- 需求是怎么一步步演进的
- 改动背后的意图

## 约定

- 一个 commit 区间对应一个 Markdown 文件。
- 文件命名：`序号-区间说明.md`，序号从 `01` 递增。
- 每次 commit 之前，把「上一个 commit」到「本次 commit」之间**用户发送的全部消息**原话记入新文件，并随本次 commit 一起提交到 `check_quest/`。
- 区间定义：从「上一个 commit」到「本次 commit」之间。
