# 鲜拾需求说明

本阶段做可运行的生鲜电商消费端，供后续攻防实验当作消费单元。范围来自 easy-vibe 生鲜微服务练习，并按当前仓库改成 Python 服务和手机号注册。

## 要做

- 官网、商品浏览、购物车、下单、订单查询。
- 管理端维护商品、库存和订单。
- 网关、鉴权、商品、库存、订单五个服务协作。
- 下单预占库存，成功后确认，失败或取消时恢复，并且可以重复执行恢复脚本。

## 不做

真实支付、短信验证码、优惠券、促销、秒杀、风控评分、自动拦截、攻击发生器和消息队列。

## 角色

- 用户：浏览、下单、查看和操作自己的订单。
- 管理员：商品上下架、改价、调库存、查看订单。注册接口不能授予管理员。
